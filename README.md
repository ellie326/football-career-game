# 벤치부터 발롱까지 MVP v0.2

GitHub Pages용 정적 웹게임입니다.

1. GitHub에서 `football-career-game` 공개 저장소를 만듭니다.
2. 이 폴더의 `index.html`, `game.js`를 저장소 최상위(root)에 업로드하고 Commit합니다.
3. Settings → Pages → Build and deployment → Deploy from a branch → `main` / `/(root)` → Save.
4. 배포가 완료되면 https://ellie326.github.io/football-career-game/ 로 접속합니다.

저장은 브라우저의 localStorage를 사용하므로 기기/브라우저 간 동기화되지 않습니다.
